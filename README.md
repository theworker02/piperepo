# piperepo

Pipe structured JSON repo payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/piperepo/

## Install / run

```bash
git clone https://github.com/theworker02/piperepo.git
cd piperepo
node src/cli.js
node --test
```
